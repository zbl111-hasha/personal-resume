# 个人简历 · HTML

一个简洁的中文个人简历页面，采用原生 HTML 和 CSS，无需安装依赖。

## 使用

直接用浏览器打开 `index.html`。页面支持手机浏览，点击右上角「打印 / 保存为 PDF」可通过浏览器打印对话框导出 PDF。

## 替换内容

编辑 `index.html` 中的姓名、求职方向、联系方式、技能、项目经历和教育背景；同时更新页面标题、描述与相关可访问性标签。

当前内容是虚构示例，只有 GitHub 链接指向仓库所有者账号。请在正式使用前替换示例信息。

## 技术

- 单文件 HTML，内嵌 CSS
- 响应式布局与 A4 打印样式
- 使用系统字体，不依赖外部资源

本仓库提供网页源码；创建仓库与推送源码不会自动启用 GitHub Pages。
